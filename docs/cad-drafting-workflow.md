# CAD Drafting

1. **Verify the source and target.** Check the live ZWCAD connection, list open drawings, and select the intended drawing. For SketchUp extraction, verify the model revision, saved scene and included geometry. Preserve originals and work on a copy.
2. **Draft at full scale.** Use 1:1 model geometry in millimetres unless the brief specifies another unit. Convert source units explicitly and verify dimension measurement factors. Use display precision that preserves the measured geometry.
3. **Use native drawing standards.** Import approved layers, linetypes, text styles, dimension styles and symbols. Use ByLayer colours and lineweights, the approved plot style, editable dimensions, and individual native blocks for reusable objects.
4. **Extract only the required geometry.** Exclude alternate copies and unused or offsite geometry. Document section levels and hidden-line simplifications. Preserve source cameras and restore the originally selected scene after export.
5. **Plot and verify.** State sheet sizes and scales in paper layouts. Check dimensions, blocks, layers, clipping, text size, scale and lineweights. Inspect each plotted PDF sheet and verify the saved drawing. Deliver links to the outputs and record any conversion limitations.
