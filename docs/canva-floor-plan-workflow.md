# APF — Canva Floor Plan

1. Verify the floor and saved plan view in the source model. Export it directly from SketchUp and place it on the designated Canva page.
2. Add native, individually editable and ungrouped dimensions, room labels and plan notations. Record units, sources and dimension endpoints. Verify any stated scale against the output.
3. Check readability, placement and measurements, then hand the deck and plan verification to APS.
