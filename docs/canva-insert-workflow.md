# API — Canva Insert

1. Start each presentation run or revision in a fresh copy of the supplied Canva design or approved template, or create a new Canva design. Treat existing designs as read-only source material. Verify the new design ID and page range before writing. Carry that new design through all stages of the same run.
2. Use the APO or APR manifest to map each approved scene image to its Canva page and frame. Upload and place the images in the native frames. Preserve project branding, proportions and crop.
3. Verify page order, images and alignment. Record design, page and frame identifiers, and hand the populated deck and mapping to APM.
