# APM — Canva Material

1. Match visible surfaces and objects in the SketchUp model to the project material sheet. Record source tab and row, exact codes and descriptions. Flag unresolved matches.
2. Put the legend beside the view and a verified keyplan on the view. Use Inter, a prominent Material legend heading, olive category headings, compact code badges and circular texture swatches. Order categories Floor, Wall, Openings, Fixtures if present, Architectural Detail, Ceiling.
3. Match the on-view callouts to the legend. Keep text, badges, leaders and keyplan markers individually editable and ungrouped in Canva. Place the keyplan drawing and swatches as separate replaceable images. Test an editable source-page transfer if the connector cannot create native elements.
4. Check codes, alignment and independent selection in Canva. Hand the annotated deck to APF.
