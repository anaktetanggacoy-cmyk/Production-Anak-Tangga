# APR — Presentation Render

1. Use the SketchUp preflight and source PNG export steps in [APO](presentation-ao-workflow.md).
2. Use the imagegen skill and built-in image editing with the actual scene export. Apply the brief and verified finishes while preserving camera, geometry, openings, furniture and framing.
3. Compare each output to its source. Revise design drift before placement. Save the inspected renders separately and record source, prompt, revision, image dimensions and check status in the manifest. Hand the manifest and accepted renders to API. Use APF and APS for measured technical views.
