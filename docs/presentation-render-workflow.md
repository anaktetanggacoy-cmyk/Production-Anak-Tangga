# Presentation Render

Use this workflow for SketchUp scenes that require rendering before placement in Canva. Follow the shared source, scene mapping, Canva layout and review practices in [Presentation AO](presentation-ao-workflow.md).

1. **Prepare the sources.** Verify the model revision and saved scene list. Export and inspect a representative PNG before batching. Copy the selected Canva template when starting a new presentation. Use the project brief, applicable material schedule and supplied mood references to guide the rendering.
2. **Render from each export.** Attach the original scene PNG to the built-in image editing tool. Preserve camera, projection, crop, room proportions, openings, furniture placement and verified finishes. Apply the requested lighting and texture treatment. Use a separate generation per scene or requested variant.
3. **Compare before placement.** Check the render against the source for geometry, furnishing count and placement, material patterns, lighting fixtures, crop and text artifacts. Revise outputs with material drift. Use the model or drawings as the measurement source. For technical plans and sections that require direct export, add verified dimensions and editable annotations to the unrendered view. Label conceptual airflow arrows accordingly.
4. **Match material codes.** Verify the schedule tab and row for each finish, opening, detail or fixture. Record the scene, surface or object, exact code and specification. Flag unmatched items. Keep render crops used as swatches traceable to the scene and use the schedule as the specification source.
5. **Place and annotate in Canva.** Put inspected renders into the existing frames. Apply the ungrouped editable legend, keyplan and callout conventions in Presentation AO. Preserve page size, frame crop, branding, footer and source links. Use the room or view title as the visible caption and record render provenance in the manifest.
6. **Verify and deliver.** Record the source export, render reference, prompt, revision, visual check and page/frame mapping. Reopen the saved Canva deck to verify the approved edits, editability, image crops and full page order and count.
