# Presentation AO workflow

Presentation AO prepares architectural presentation pages from saved SketchUp scenes and places the original PNG exports in Canva.

1. **Confirm the brief.** Identify the project, milestone, SketchUp model revision, scene range, and Canva reference or destination. Confirm the model and Canva connection before editing.
2. **Check the sources.** Use the current drawings and drawing schedule for official room names, codes, dimensions, and levels. Record discrepancies before adding annotations.
3. **Map scenes to pages.** Read the saved scene names and order from SketchUp. Record the source scene, output filename, image dimensions, and destination page. Report gaps in scene numbering.
4. **Export directly from SketchUp.** Test one PNG first. Check camera framing, visibility, image dimensions, and aspect ratio. Export the remaining scenes at consistent settings. Verify the files on disk if an export call times out, since SketchUp may finish writing afterward. Restore the originally selected scene.
5. **Prepare the Canva design.** Copy the supplied reference or approved milestone template when creating a new presentation. Preserve its page size, typography, borders, and logo. For a new layout without a reference, follow the studio guidelines for Inter typography, a warm white background, and clear page borders.
6. **Place the exports in Canva.** Upload the PNGs directly to Canva and replace the images in the existing frames. Keep the scene labels aligned with the scene-to-page map and check image proportions and crop. Replace sample project text with verified project details.
7. **Review and deliver.** Check every page for the correct view, readable labels, crop, and alignment. Preview the draft and get approval where the Canva editing flow requires it. Save the design, verify the page count, and deliver the Canva link and scene-to-page map.
